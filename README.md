# Uptime telegram bot
## Описание 
#### telegram bot, через который пользователи добавляют сайты, у которых хотят отслеживать доступность.

# Особенности

- Аутентификация через `fastapi` сервер, который отправляет код доступа на email пользователя
- Регистрация с помощью `JWT` и device id(fingerprint)
- Реализация воркеров:
  - отправка сообщений на email
  - отправка head запросов к отслеживаемым сайтам
  - рассылка пользователям через telegram bot о доступности\падении сайтов
- Планировщик задач `celery`, который взаимодействует с воркерами, заполняя их задачами
- Отдельные базы данных(`postgres`) для самого проекта и тестов(изоляция)
- Запуск множества настроенных контейнеров с помощью `docker-compose`
- Отслеживает доступность сайтов каждую минуту(Скорость примерно 20к сайтов за 40сек)
